## AI 打图接口（AgentEnv）

`ark_emulator/agent_env.py` 提供 Gym 风格环境，AI（RL / LLM / 搜索）可直接"打图"：

```python
from ark_emulator.agent_env import AgentEnv

env = AgentEnv("level_main_01-01",
               squad=[{"charId": "char_002_amiya", "phase": 2,
                       "level": 50, "skillIndex": 2}])
obs, info = env.reset(seed=123)                 # 全量快照
obs, reward, done, info = env.step({            # 每步一帧
    "type": "deploy", "charId": "char_002_amiya",
    "row": 3, "col": 4, "direction": 1})
```

- 动作：`deploy` / `withdraw` / `skill` / `deploy_summon` / `deploy_token` /
  `pause` / `resume` / `step_ticks`；非法动作返回 `info["invalid"]=True`
  而不崩溃。
- 观测：`snapshot()` 全量（时间/费用/生命/干员/敌人/弹道/事件/统计…），
  事件按 seq 增量。
- 奖励（可配权重）：击杀 +10、漏怪 -20、部署 -0.5、技能 -0.1，
  胜利 +100 / 失败 -50；`info` 含 tick/result/stats/生命/费用。
- 辅助：`deployable_chars()` / `buildable_cells()` 供规划器使用；
  `play_random(env, steps)` 随机策略演示。
- **合法动作空间**：`legal_actions()` 返回当前可执行的 deploy/skill/
  withdraw（校验费用、再部署冷却、部署上限、占位、SP 就绪、已装备技能）；
  `step(None)` 表示等待（推进 1 帧）。
- **奖励塑形**：额外权重 `damage_reward`（对敌伤害）、
  `damage_taken_penalty`（我方承伤）、`time_penalty`（每帧计时），默认 0。
- **批量环境**：`BatchEnv(n, ...)` 同步向量环境，`reset_all(seeds)` /
  `step_all(actions)` / `legal_all()` 一次跑 N 个种子。

演示：`python examples/agent_play.py`（随机策略）、
`python examples/agent_greedy.py`（贪心防守策略）。

**脚本化智能体**（`ark_emulator/agents.py`）：`GreedyDefender` 基于
`legal_actions()` 的启发式策略（部署先锋/重装/医疗/术师、技能就绪即放、
低血量撤退），`play_episode(env, agent)` / `evaluate(levels, seeds, ...)`
（BatchEnv 扫掠）直接可跑，作为 RL/搜索策略的基线。

**批量基准**：`ark_emulator/benchmark.py` 的 `run_benchmark()` 对
关卡 x 种子 批量评测并输出 JSON 报告（胜率/击杀/漏怪/部署/结束 tick），
当前基线快照在 `examples/benchmark_report.json`。
