M81 recursively rejects duplicate object keys with object_pairs_hook. Each reference line is parsed and checked before its branch write: required event shape; finite JSON payload; positive integer id/non-bool; integer nonnegative time; event name; earlier integer cause; contiguous IDs and nondecreasing global time. Nested objects and dictionaries in arrays use the same parser. Reads of an owned journal also use the strict record parser. Complete UTF-8 encoded bytes and insertion order are preserved; the source reference remains immutable.

Any reference copy/parse/hash/size/count/write failure discards the new branch. EventLog.restore also discards a successfully copied branch if its later next_id/record validation fails, preserving the old log until complete admission. A valid first prefix followed by a bad second line therefore cannot leak a halfaccepted branch or publish partial EventLog state. These changes do not invent replacement records or modify World/RNG/scheduler math.
