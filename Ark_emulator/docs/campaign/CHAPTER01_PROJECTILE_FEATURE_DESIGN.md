## Content and pure interfaces

Add a generic projectile definition collection; damage/heal/area effects opt in with an exact `projectile_definition` reference. Old content takes its old path with no new default state or events. Definitions specify motion and collision exact rule references, lifecycle numeric/boolean limits, explicit invalid/hidden policies and on-invalid effects. Missing fields, wrong kind/contract, invalid boolean/number/policy fail compilation.

Reuse existing declared pure `projectile.trajectory` and `projectile.collision` contracts; no new numeric catalog or default bindings are required. Trajectory inputs use actor snapshots, previous/current points and age/delta/lifetime/profile parameters; its plan contains finite position/height, reached and optional motion-state. A replaceable provider gives homing planar5 with visual parabola, fixed attach or live follow. Collision is a replaceable pure policy with projectile/actor/spatial snapshots and outputs trace-target hits/terrain-stop. Default mathematical swept trace-point collision is not native actor-body or terrain calibration. Native random height/arc fields are zero/false, so the profile does not silently draw RNG.

## Persistent lifecycle and callbacks

ProjectileSystem keeps canonical source/trace-target IDs, attachment target ID, launch/fixed/last point, source/cast snapshot, hit identities/count, owned step/expiry jobs and lifecycle state in World. Effects launch synchronously in the existing atomic cast transaction. Motion updates happen on owned discrete jobs after command/movement observations. The declared expiry task precedes same-tick projectile motion; explicit expiry-reach then hit then invalid/cast completion ordering is model policy. No duplicate terminal/cast completion or hit beyond maxHit is allowed.

Normal stops after its accepted first hit. C4 remains attached until expiry despite maxHit1/stopAfterMax false, then resolves its packet/area at actual stored attachment position and releases cast pending count. C4 fixed_at_attach is default because source follow flags are false, but native parent-transform attachment can still follow without that flag: native meaning remains pending. A live-follow replacement profile is independently exercised with real target movement commands. Target invalid retains the last/fixed point for C4; normal cancels instead of retargeting. Source invalid retains launched objects separately from source cast retirement. Hidden policies obey visibility filters and never allow a captured target to bypass default damage filtering.

Explicit area center_position is a finite geometry value injected by the projectile callback, not fabricated World actor coordinates. It allows a retained-point explosion to select living neighbors after the original target retires. Native area radius/body and packet multiplicity are pending; two-full and first-signal profiles remain explicit alternatives.

Projectile jobs carry instance ownership rather than masquerading as ability tasks, so interrupting source casts does not accidentally delete detached launched objects. Attack recovery claim pruning must account for active projectile cast groups, preventing a late packet from claiming a second attack after a newer cast. Waiting cast pending counts use existing projectile_started/finished hooks and are restored atomically with object state/jobs.
