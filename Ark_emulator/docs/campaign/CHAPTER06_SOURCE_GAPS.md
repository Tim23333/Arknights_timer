# 第六章来源复核与待修项

当前七个普通变体的定义组合、基础数值与引用闭包已核对；这不等于全部行为通过。普通Boss和剧情_s两变体、机关、地图、NPC与故事组合继续开发。

普通Boss旧6e88的Cold时钟反例已由独立来源复核发现：普通攻击timeMode0只缩放前摇而未缩放总动画忙碌时长。新ff106按Normal0／Burst1的真实timeMode分开，Cold.7下普通40／69／159，冰爆固定28／48或87／110；属性／伤害／重生／分支保持原source。新时钟独立复核继续。CP306的三向差异已另定位为观察者调用非纯属性读取新增9条计算日志，不修改内核去抹掉事件；新验证使用纯状态读取。

剧情_s原完整流程26507events已经结束且CP／head一致，但冰封资格有实际内容缺口：模型用deployable表示“角色占格”，三位真实NPC没有deployable而仍是CHAR1，所以其占据格可在捕获时被选中。独立真实煌实例反例7a55ccf8...保留；不会凭整关确定性自动签来源准确性。

Root随后在真实当前dump.cs435504找到TileSelector.FilterType的EXCEPT_CHARACTER=2声明（整源SHA18c43dde...、提取记录450f6d09...）；旧源资产与此声明的版本差异、方法正文均仍未证明。[PRTS霜星S](https://prts.wiki/w/%E9%9C%9C%E6%98%9FS)描述冰封可部署地块并击倒其上的我方单位，但没有明确捕获时与结算时的占位条件。当前替换政策据此分开记录：捕获时排除既有友方CHAR，结算时仍处理后来出现的占格角色；这是来源枚举与资料的明确解释，不宣称已证原生方法体。

通用查询新增实际typed selection-state与side/unit-type位投影，内容以侧别和CHAR位定义资格。NPC不增加部署能力、不改变原生槽位，TOKEN和敌方同类型角色可单独保留；新ordinary/_s内容在联合候选上实际复核后重新运行原关，旧报告保持历史身份。

## 已发现的实际索敌错误

独立公开部署反例中，术师已有真实阻挡目标3，另一个范围内合法目标5拥有极高嘲讽；现snmage_v2却连续攻击5。原生普通节点及技能使用INPUT_TARGET2，按已有来源模型契约应把实际阻挡对象作为硬资格，不能以有限排序常数代替。

新内容修订需把原range／side／motion／category／camouflage等资格与实时blocked_by目标约束合取。真实阻挡者无资格时不能回退到其他目标；没有阻挡时保持原索敌。首帧需要先结算实际阻挡再捕获目标时，用现有可选settle_blocking能力，不在内核按敌人ID分支。普通攻击和Cold技能都须独立验证。旧6ec208模块和完整反例保留，未改期待去接受错误目标。

相同Source2输入的冰弩手也正在独立核对，不能从其无阻挡测试通过推出阻挡场景正确。

后续复核已完成：新snmage_v3与snbow_v2实际通过原19项不变期待和6项新边界；范围／原生资格与实际阻挡目标合取，失去合法阻挡者时不回退攻击旁边目标。旧17pass／2fail报告保持原身份。

NPC低血量天赋也发现了动态状态遗漏。煌v5只读取基础maxHP和静态禁疗，独立两反例已保存；v7改为有效maxHP／Buff派生禁疗，原3输入与同帧两包一次恢复的实际检查点／重放通过。扩展独立复核仍进行，原生同帧回调顺序继续标记为明确参考政策。

真实map中的栅栏palette声明FLY_ONLY／MELEE，所提取tile prefab默认data为0，来源版本或实例覆盖关系有冲突。新泛用静态地块声明精确绑定关卡palette，空黑板／effects才接受；这项声明和3组原路线传送的实际完整续跑／重放已验证，独立联合底座门仍待完成。它没有将非空未知机制当作普通地块。

## 资料佐证与范围

[PRTS雪怪狙击手页面](https://prts.wiki/w/%E9%9B%AA%E6%80%AA%E7%8B%99%E5%87%BB%E6%89%8B)列出的通常级别0数值为HP2500／ATK290／DEF80／RES0，攻击范围1.9、间隔2.4秒；说明不能攻击飞行单位，计算伤害时对冻结目标使用150%攻击倍率。它们与本关固定exactDbRef数据吻合。页面是通常数据，关卡override仍以固定关卡引用和源表为准。

该页面没有证明来源死亡后，被动伤害hook是否继续附着于已经发射的箭。当前模型在来源死亡、拥有者被动清理后，保留箭对DEF100目标造成190；来源仍活跃且目标冻结时为335。这个来源寿命解释保存为可替换live-owner-hook政策，死亡场景的确切原生倍率仍待证，不把字段未提及例外自动解释为335或190已准确。

攻击前摇的ASPD缩放也有明确政策边界：目前消费affectedBySlowDown／timeMode并用normalized ratio最小.01处理，寒冷.7的实测模型结果已保存；maxAnimScale与原生动画上限的精确关系尚未校准。可以替换规则，不能在报告中抹去该项。

## 冻结与SP恢复

现有寒冷来源数据给出异常标记和攻击速度修正，冻结控制限制移动、攻击、技能。`frozen_recovery`是可显式绑定到某项资源的可替换规则；受控测试证明了该规则能冻结SP，不证明所有实际冻结都自动阻断自然技力回复。

攻击回复的术师在冻结期间无法攻击，因而没有攻击事件的SP收入；这个结论应与时间回复的计时器是否停止分开。每个真实资源消费者依据其恢复类型、字段和来源单独绑定，未证明的普遍SP暂停不能自动套到固定12人。

## 完整验收仍缺什么

新增内容须保存独立目标资格、来源属性、技能／被动／弹道、控制与生命周期的实际执行证明。旧模块数值正确或编译闭包通过，不掩盖来源复核发现的行为缺口。单机制、明确参考政策、整关全程与用户后续实机反馈继续分列；当前不签第六章整关。
