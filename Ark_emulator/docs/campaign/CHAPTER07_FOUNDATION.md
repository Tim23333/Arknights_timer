## 真实地形参与目标资格计算

选择器的 `eligibility.include_candidate_tile` 是严格布尔值，默认不提供地形输入。
启用后，`targeting.eligibility` 收到：

```json
{
  "candidate_spatial_tile": {
    "cell": {"row": 1, "col": 2},
    "tile": {"buildableType": 2}
  }
}
```

这里的 `tile` 是候选目标当前位置投影到实际网格后取得的完整地形记录，上例仅节选一个字段。
地形覆盖、目标移动和格投影均在查询时生效；缺少位置或投影越界会明确拒绝。
资格判断与排序规则分开：内容先判断地形、阵营、运动类型和状态是否允许，再按自定义规则排序。
爱国者投矛可以先筛选实际高台目标，再按嘲讽和距离选择；不需要用额外巨大优先级模拟资格。

## 复活等待期的有限动作权限

单位保留 HP 为 0、`active=false`、`alive=true` 和真实复活等待状态。
内容在既有 `rebirth` 配置内声明有限的允许列表：

```json
{
  "retain_buffs": ["buff/custom/waiting_timer"],
  "waiting_actions": {
    "abilities": ["ability/custom/waiting_pulse"],
    "buffs": ["buff/custom/waiting_timer"]
  }
}
```

每个允许动作必须是该单位拥有的 `manual`、`auto_only=true` 能力；允许的 Buff 必须声明保留。
实际调用由该单位自己的保留 Buff 周期回调发起。权限同时绑定单位生命周期代次、复活代次、
Buff 实例与代次、能力 ID，以及真实调度中的复活完成任务和时间。
设置世界状态中的 `waiting` 字段不能授予权限，手动技能命令也不能借用周期回调权限。

能力启动后保存对应权限，生效回调重新验证。源中心范围效果允许从等待期的真实位置计算，
目标仍经过正常活动状态和资格判断。复活完成、取消或权限失效时取消尚未生效的等待期动作。
伤害、费用、技能冷却、控制状态和选择规则仍由既有领域与内容决定。

## 多个来源共用一个不叠加光环效果

光环内容显式声明共享租约策略：

```json
{
  "lease_policy": {
    "mode": "shared",
    "identity": ["definition", "target"],
    "source_binding": "oldest_live_lease",
    "external_child_collision": "reject",
    "owner_activity": "active_or_rebirth_waiting"
  }
}
```

同一定义与目标只保留一个效果实例、一个叠加层；每个真实光环父实例持有独立租约。
第二个来源进入时增加租约而不刷新效果；一个来源离开后其余租约继续，最后一个来源离开时移除效果。
涉及来源属性的规则按最早仍有效的来源重新计算。相同 ID 的外部效果发生冲突时明确拒绝并回滚。

`owner_activity` 默认是 `active_only`。允许复活等待期持续光环时，还须认证真实保留父实例、
当前单位代次、HP 为 0，以及实际复活完成任务或内部复活开始事务；世界标志无法伪造有效租约。
共享光环权限与等待期能力权限分别处理，光环声明不授予技能或弹道执行权限。
