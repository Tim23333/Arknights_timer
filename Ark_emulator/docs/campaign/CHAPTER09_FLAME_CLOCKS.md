# 焚毁者施法与能力时钟原型

固定技能黑板和Buff模板分别声明施法状态10.6秒、状态内6秒触发更新、冷却10秒、发包间隔0.5秒。
这些时钟属于不同职责，不能简单以飞弹寿命或单一攻击间隔替代。
来源为第九章`enemies.native.v1.json`中的Flame技能，以及`enemy_duspfr_flame[cd]`模板。
参考语义同时保存在`linked_elemental/flame.reference.policy.v1.json`。

隔离ability-clock候选新增两种通用内容动作：

- `set_ability_cooldown`核对目标实际拥有的ability，时长调用已有`ability.recovery`与`time.quantize`计算接口，支持效果局部规则和能力局部规则。
- `interrupt_ability`只取消明确指定、实际拥有的能力及其任务和所属连接，不按角色ID区分。

生命周期关联引用要求ability已由实际实体依赖闭包加载，禁止缺失引用；
这类“能力→所属Buff→能力时钟”关联不作为递归加载同一能力的依赖循环。
静态与运行时均验证字段和时长，负值、布尔伪数值及非有限值拒绝。

源施法原型已实际运行：第0刻进入状态并清冷却，第180刻将ready设为480，
第318刻状态结束，中断连接并将ready设为618。首连接按明确的planar速度10参考推进，
18／33／48刻等每15刻执行一个独立生命60与EP30包；对RES20生命实伤48。
这一first-contact参考不是原生Harpoon方法体或客户端帧验证。

真实源状态变成SILENCED后，连接取消事件使施法状态和能力结束并开始10秒冷却；
后续不再发包。实际磁盘检查点在6秒脉冲前保存，恢复经过脉冲与10.6秒结束后，
完整检查点与公开命令从头回放一致。当前属性改变时普通伤害与EP分别按当前源／目标值计算。
