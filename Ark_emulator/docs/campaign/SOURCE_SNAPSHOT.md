# 源码与证据快照

本次提交按显式路径清单收录 V2 源码、内容包、场景操作、测试、生成与审查工具及文档，
同时收录当前生产底座完整回归、0-1 身份、独立复核、推广与关卡输入的必要小收据。
清单工具为 `tools/prepare_source_commit_v2.py`。
当前冻结清单在 `validation/campaign/source_commit_v2/manifest.json`，
列出每个文件的 SHA256，并记录未收录但仍保存在磁盘的运行证据。

固定源文件、内容包和收据通过仓库 `.gitattributes` 保持原始字节；
源码身份、规则身份与内容身份因此可以跨检出核对。
历史实验工具、补丁和来源摘录保留其原空白与换行，不能为了格式检查使已冻结摘要失效。
生产源码和当前新增工具的差异格式检查另行执行。

完整事件日志、捕获、检查点及连续回放的巨量文件保留在本地验证目录或 E:/ArkSimEvidence，
不作为源码提交。部分历史工具和小收据指向这些本地证明，
查看这类证明需要原证据目录；新检出可重新生成当前运行证据。
源码提交不是在另一台机器上已经执行回归的证明。

本次范围仅涉及 Ark_emulator 与原字节规则 `.gitattributes`，
工作区的 Ark_data 解包产物、后端打包配置和内存工具其他改动保留。
第九章来源准备在这个清单冻结后继续开发，完成后另行加入新的来源与消费者批次。
