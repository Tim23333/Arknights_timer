# 光环、固定单位及首关敌方攻击进展

本阶段仍在固定12人、36个标准主线尾关的持续目标内。新增通用执行机制与真实
来源转换，未将部分技能原型、基础单位或初级敌人的通过提升为完整关卡。

## 新增通用能力

- Buff.aura：持续成员管理；parent/child身份独立；立即应用，资源恢复前及移动后重算，
  效果阶段位移同事务同步重算，新演员创建后立即加入；离开、source/center死亡与撤退、父实例移除或半开到期清理。
  到期清理位于阶段0命令/波次任务之前，防止到期同tick的at_cast快照采到过期增益；
  到期前已捕获的历史快照仍保持当时属性。
- regenerate：用可替换healing.base数值合同回复HP，仅产生regeneration.accepted，
  不触发healing.accepted订阅；有效源属性实时采样。
- selector.limit_attribute：目标上限读取来源有效属性，外部Buff或自定义公式可修改。
  明确拒绝负数/非整数；原有limit:null无限目标行为保留。
- damage_types：默认仅physical/arts/true，未知类型明确拒绝，避免拼写错误静默退成物理伤害；
  扩展类型须显式能力声明及支持该类型的自定义管线。

独立复核发现的effectphase位移晚一tick更新及未知伤害名称退成物理伤害均已经修复，
保留原失败预期与反例。无官方角色ID分支进入通用执行代码。

## 独立发现的技能结束边界

Buff严格半开结束，但技能mode资源当前在effectphase的ability.finished反应中还原。
跨线复核对齐攻击时钟后，实际发现风笛在endtick600可采到mode1/已无Buff的三击，
能天使在450可采到mode1/已无连射Buff的一击，艾雅法拉的显式probe在450也可能接受mode1。
这是未闭合的原生mode detach/末tick FSM契约，已明确保留pending；
它不影响已声明的中段数值组合预期，但禁止据此声称完整持续技能或正式干员已经完成。
后续真实单位整合须解决模式与Buff的结束顺序并保留这些实际反例。
