A blocking.changed toggle-child callback legally retires its source obstacle. M55 subsequently publishes a relation from its captured obstacle list to a second mover after the obstacle's retirement. Final snapshots alone conceal this because a later tick clears the relation. The independent expectation forbids that stale event after entity.withdrawn.

M57 re-reads active participants, ground/hidden/forced state, current contact distance and actual remaining selected weighted path before accepting and publishing obstacle membership. Ordinary blockers are also checked against their current activity, control and capacity. Calculation callbacks that change facts request a fresh pass. Synchronous relation callbacks are detected using immutable actor snapshots. Reentrant requests are drained in the same atomic operation, with a reaction-budget bound and finally cleanup. An invalidated relation is cleared only while it still equals the captured relation; a callback's replacement relationship is retained and re-evaluated. No new unweighted path is invented when terrain invalidates the selected path.
