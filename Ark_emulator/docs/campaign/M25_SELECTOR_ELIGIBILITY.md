## Generic interfaces and declared policy

`selector.eligibility={rule,parameters}` opts in. Parameters explicitly declare complete typed `defaults`, raw `source_configuration`, `side_policy:relative_ally_enemy`, and `neutral_policy:reject|absolute_mask`. There is no implicit default qualification definition/binding or actor state when the field is absent. Every reference is exact-kind and exact `targeting.eligibility` contract checked by Compiler/capability preflight.

The pure contract receives source/candidate snapshots, selector configuration and source/candidate selection-state snapshots; it returns strict `{accepted:bool,reason:string}`. SpatialSystem.qualifies(source,candidate,selector,ability=None,effect=None) checks active/alive/route visibility, then uses RuleRuntime.evaluate directly. It never calls calc, sorts, samples, emits, prunes or caches. select calls it after geometry and before score/order/RNG. Sibling M24 pure candidate query should use the same call at the same point; no M24 file was edited here.

`components.selection_state` contains typed side/motion/category/profession/unit-type fields, boolean target_free/ally_target_free/heal_free/camouflage/source camouflage capability and explicit abnormal/cause index lists. `Buff.selection_flags` may only contribute booleans/status/cause sets, combined by union. Each query reads live instance expiry against now, using half-open expires>now; it does not invoke Buff.controls/prune. Independent contributors remain effective until their own expiry/removal. Stun/invincibility/skill-not-activatable/teleported do not become target-free. Only explicit named TARGET_FREE2/ALLY_TARGET_FREE15/HEAL_FREE7/CAMOUFLAGE17 flags map to corresponding statuses.

Side2 is explicitly modeled as relative-to-source enemy; it is not claimed as recovered absolute native interpretation. Neutral handling and missing state defaults are explicit mathematical choices. A stage author must supply actual actor state where known, particularly nondefault category/token type/motion/profession; the supplied probe defaults are not universal claims about all fixed12, tokens or devices. Partial target-free ignore uses declared reason sets; unaccounted causes cannot be bypassed. Camouflage requires a declared source capability or explicit force-ignore. Heal-free is applied only to queries carrying healing intent. Generic custom pure rules can replace eligibility; geometry/provider/score/selection remain separate.

This qualification concerns prospective targeting. Existing captured casts/projectiles remain governed by their separately declared lifecycle/hit policies; target-free is not converted to invincibility or silently used to cancel an already launched packet. Native acquisition-versus-captured-target semantics are pending.
