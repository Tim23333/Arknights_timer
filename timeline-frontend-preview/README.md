# Timeline 主程序新前端原型

打开 `index.html` 即可查看。这是暂不依赖 Electron 的独立 Web UI 原型。页面里的战斗数值、设备状态和导出的 `demo: true` JSON 都是模拟样本，不调用游戏内存、ADB 或 Qt。唯一真实网络操作是用户主动点击“检测可达性”时，对本机现有 `/v1/game` WebSocket 接口发起只读订阅检查。

游戏时钟位于页面最上方的抽屉：默认展开且置顶，时间使用更大、更粗的等宽数字，并同时显示逻辑帧和计时器链来源。抽屉柄控制展开/收起，“已置顶／置顶时钟”按钮控制滚动时是否固定在顶端；总览中的时钟卡同步显示同一个值，不另建采样链。顶栏把“选择 ADB”与使用教程、寻址工具、排轴工具、缓存导出、接口说明放在同一行，窄屏可横向滚动，不收进“更多操作”菜单。首屏“数据总览”还分别标明敌我完整帧、操作记录、随机数和 WS 服务的采样状态。下方四个模块都可在原位展开，展开后复用完整监控内容，不裁剪表格、列设置、扫描与导出操作、实体详情入口或 RNG 预测/历史。左侧抽屉只列监控模块与运行设置；点击顶栏标题返回数据总览。运行设置同时包含字段策略。操作反馈使用可关闭、分级定时的右上角气泡提示。抽屉与气泡交互参考 AngelinaTravelToolbox 的现有前端，但保留 Timeline 自己的内容层级。

## 与现有源码的对应关系

| 原型页面/入口 | 现有实现依据 |
| --- | --- |
| 顶部 ADB、教程、寻址、排轴、缓存和接口入口 | `backend/desktop_app.py` 的 `CoachWindow._build_ui()` |
| 游戏时间/逻辑帧与敌我完整帧分别展示 | `backend/desktop_app.py` 的计时器刷新和 `EnemyPollWorker`；二者不是同一条采集链 |
| 敌人扫描、出怪导出、精确坐标、隐藏离场、显示列、精度、迷你模式 | `backend/desktop_app.py` 敌人区块；`backend/app/enemy_ui.py` 列定义 |
| 敌人路线、动作、属性、损伤条、Buff、技能、生效帧详情 | `backend/app/enemy_ui.py` 的 `EnemyDetailDialog` |
| 干员扫描、召唤物过滤、无来源总伤、数据总览、显示列、精度 | `backend/desktop_app.py` 干员区块；`backend/app/character_ui.py` |
| 干员属性、伤害统计、技能、状态、Buff、天赋、元素损伤等详情 | `backend/app/character_ui.py` 的 `CharacterDetailDialog` |
| 关卡/操作扫描、部署/技能/撤退历史和 JSON 导出 | `backend/desktop_app.py` 操作记录区块；`tools/deploy_tracker` |
| 战斗随机与表现随机、预测数 1–500、预测/消耗表和分路导出 | `backend/desktop_app.py` RNG 区块；`tools/ak_live_rng` |
| WS 总开关、实际 topic 默认/范围 | `backend/desktop_app.py` 自定义选项；`backend/app/services/websocket_api.py` |

**排轴工具是独立 Vue 页面**，源码位于 `frontend/src/App.vue`。它负责关卡地图与出怪/我方操作时间轴，不是这个主程序实时监控页面的首屏；本原型恢复其可见入口，但点击只显示说明，不启动独立页面。

## 现有能力与规划能力的边界

现有的“同步扫描精确坐标”“无来源总伤”是实际采集控制；“显示列”只是 UI 显示策略；WS `topic/rateHz` 是发送策略。运行设置里的“字段策略”展示未来的每字段采集/显示/WS 三开关，**后端目前没有实现**，切换这些开关不会修改真实 Timeline 配置。其依赖示例来自 `UsedMD/TIMELINE_FIELD_DEPENDENCY_MATRIX.md`，只供评审交互，不应当作已落地功能。

“检测可达性”以当前原型勾选“WS 发布”的字段作为待测清单，连接 `ws://127.0.0.1:8765/v1/game`，订阅其对应主题并检查是否实际收到有效字段值。空的异常状态或事件数组也可能是有效值；不存在场上实体时，其详情仍视为未验证。它会逐项区分“已收到”“主题未收到”“字段为空”“当前协议未暴露”“未采集”和连接/订阅失败；仅收到 `game.ready` 或运维心跳不会算通过。这个检查**不能证明原型勾选已同步到真实服务配置**，也不保证后续帧持续可用。浏览器若阻止本机 WebSocket，结果会明确显示连接失败。

敌我列表属于完整帧；计时器、操作历史、RNG 与异步完整详情有各自的时效语义。原型在界面中保留这种区分。
