## 天赋：来抓我啊

> 部署后X秒内，攻击使敌人法术抗性-X%（持续X秒），且优先攻击未获得此效果的敌人

### 猫式起爆龙弹（Token 技能）

> 对前三个敌人首次进行攻击时改为使用"猫式起爆龙弹"。来自我方其他单位的伤害会将其引爆，造成罗德岛隐秘队XXX%攻击力的伤害和XX秒晕眩，并回复1点部署费用。"猫式起爆龙弹"在被引爆后或30秒后消失

| 等级 | ATK伤害倍率 | 晕眩时间 |
|---|---|---|
| I | 150% | 2.0s |
| II | 230% | 2.2s |
| III | 280% | 2.4s |
| IV | 350% | 2.6s |
| V | 420% | 2.8s |
| VI | 500% | 3.0s |

**Blackboard 参数：**
- `attack@boom_duration` — 5.0s（炸弹存在时间）
- `attack@atk_scale_boom` — 1.0（基础爆炸倍率）
- `attack@cost` — 3.0（费用）
- `attack@stun_duration` — 3.0s（基础晕眩）
- `attack@max_boom_cnt` — 3（最大炸弹数）
- `max_cnt` — 4（最大数量）

### 区域覆盖（Token 被动）

> 效果范围内，莱茵生命携带的技能变化，范围内的友方位为莱茵生命援军
