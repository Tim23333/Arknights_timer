# ArknightsTimeline v3.5.3 更新公告

发布日期：2026-08-31
桌面程序版本：v3.5.3
排轴工具前端版本：v1.0.2

## 本次重点

### Guest 侧自动寻址

- 新增「启用自动寻址」选项，通过 ADB + memsrv 直接读取 Android guest
  中的 `BattleController` 时钟。
- 自动定位逻辑帧和战斗时间，不再强制依赖 Windows 宿主进程的手动寻址。
- 地址在游戏重启后失效时可自动请求重新定位，并显式释放旧 memsrv 通道。
- ADB 地址优先沿用当前选择，回退时读取持久化配置，兼容模拟器端口变化。

### 关卡切换自动刷新

- 可自动识别战斗时间开始走动与新关卡载入时的归零事件。
- 检测到关卡切换后，依次刷新：
  1. 操作记录；
  2. 敌人/干员实时数据；
  3. 战斗随机数与表现随机数。
- 每一步具有超时、失败重试和中止反馈，避免多个扫描流程并发重入。

### 自定义选项与气泡日志

- 新增「更多自定义选项」折叠区，集中管理自动寻址、自动刷新和气泡提示。
- 气泡提示支持 trace/debug/info/warn/error 五档独立展示时长。
- 提示等级与成功/错误视觉语义分离，手动扫描和自动刷新均有明确反馈。
- 配置写入 `custom_options.json`，下次启动自动恢复。

## 稳定性修复

- 修复主界面时钟恒为 0 时误判关卡切换的问题。
- 修复关闭自动刷新后旧定时等待仍可能在以后重新触发的问题。
- 增加等待链代际控制，快速关闭再开启时旧轮询不会加入新一轮刷新。
- guest 时钟换源或游戏重启重定位时完整重置关卡检测基线。
- 手动宿主寻址与 guest 寻址现在共用同一套时间走动/归零检测。
- 将“持续归零锁存”和“一次性待消费事件”分离，同一个归零窗口只触发一次。
- 归零订阅者广播移到 provider 主锁之外，避免慢回调阻塞采样。
- 后台内存线程只发送重定位信号；Qt worker 的创建与启动统一回到 GUI 主线程。
- 修复重新寻址成功后旧时钟通道未及时关闭的问题。

## 数据与构建更新

- 合并 PR #3 的 guest 自动寻址、关卡自动刷新、自定义选项和 toast 功能。
- 使用更新后的 `Ark_data/dump.cs` 重新校验并生成运行时偏移：26 组结构、
  4 组枚举。
- 按 base（2026-07-22）+ hot（2026-08-19）覆盖规则重新提取 26 张游戏表。
- 重建数据后包含 1368 个干员/对象、1803 个技能、2130 个敌人、3522 个关卡，
  静态 handbook 表解析出 1694 个敌人名称。
- 重新编译并内嵌 aarch64 静态 memsrv v4。
- Ark_emulator 删除 `G:\Arknights` 机器绝对路径，数据、解析脚本、Spine 库和
  2853 条关卡资产索引全部改为项目相对路径。
- 前端升级并锁定安全构建依赖：Vite 7.3.6、PostCSS 8.5.26、Nanoid 3.3.18；
  `npm audit` 为 0 漏洞。
- 修复 PyInstaller 在外部 PATH 中误收 Poppler ICU、导致 PySide6.QtCore
  启动报错的问题；构建时会隔离非系统 ICU。

## 升级说明

1. 关闭正在运行的旧版程序。
2. 用 `ArknightsTimeline_v3.5.3.exe` 替换旧 exe。
3. 建议保留旧版同目录下的 `custom_options.json` 和需要继续使用的缓存文件。
4. 启动后可在「更多自定义选项」中开启自动寻址与关卡切换自动刷新。
5. Guest 侧功能需要 MuMu 模拟器 ADB 可连接并已开启 Root 权限。

首次运行若被 Windows 安全提示拦截，可核对上方 SHA-256 后选择继续运行。
