# Arknights Timeline v3.6.1

发布日期：2026-10-09。前端版本：1.0.3。

## 修复与数据维护

- 修复扫描线程销毁后遗留的读取器 Signal 回调，保留运行期异常处理。
- 修复空帧值变为第 0 帧的排轴播放问题。
- 修复 WebSocket 空详情残留和换局详情 revision 未重置的问题。
- 部署首次状态读取在后台完成，减少主线程等待。
- 主程序以普通 Windows 权限启动；宿主进程寻址工具继续按需申请管理员权限。
- 统一从 `game_data/` 加载游戏版本数据，基础包与热更按逻辑表名覆盖。
- 移除解析器固定哈希表路径，新增 `更新游戏数据.bat` 完整更新入口。
- 支持 EXE 旁外置数据目录及 overrides 手工修正，缓存随数据版本失效。

## 当前游戏适配

资源由当前 PC 基础包和热更提取，Android 结构从 MuMu 2.7.81 的 live 字段表读取。
当前数据版本为 `2026-10-09-8871109a420c`，PC/Android profile 分开保存。
修正新版敌人、干员及 Ability 字段布局，增加阻挡管理器的中间层读取。
动作帧提取适配 Spine 3.8 大端标量编码。

## 输出

- `ArknightsTimeline_v3.6.1.exe`：正式版，无诊断日志窗口。
- `ArknightsTimeline_v3.6.1_Test.exe`：测试版，含独立诊断日志窗口及日志打包功能。

两版使用同一份代码和数据，均内嵌寻址工具与 memsrv v5。
直接运行 EXE 使用内嵌数据；放置外置 `game_data/` 后优先加载外置目录。
数据维护与本次有限场景验证证据见 `docs/game_data.md` 和
`docs/GAME_DATA_UPDATE_20261009.md`。
