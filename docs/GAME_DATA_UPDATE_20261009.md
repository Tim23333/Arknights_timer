## 修复

1. 敌人扫描线程结束时解除读取器对其 Signal 的引用，部署读取器也解除临时回调。
2. 未知帧值保持 null，不会变成第 0 帧出生或部署。
3. 详情集合清空时增加 revision；换局时重置详情 revision。
4. 基础包和热更按逻辑表名覆盖；失败提取保留旧输出。
5. 解析器和运行时通过统一数据入口寻找表和目录数据，移除固定哈希输入路径。
6. 部署首次状态在后台线程获取，主线程消费快照。

新增完整更新入口 `更新游戏数据.bat`。生成阶段先使用缓存副本，验证后再切换
数据目录，保留 overrides。ADB 命令明确限定本地模拟器序列号。

## 新版本适配

Android 偏移由模拟器中的 live IL2CPP 字段表读取，APK metadata 提供字段名称，
共更新并验证 39 组结构、4 组枚举，关键字段和映射全部存在。
PC profile 单独保存，不会加载到 Android 读取器。

敌人相关字段有 0x8 的移动，干员多个字段位置改变。干员阻挡数据改为
Character → BlockManager → BlockedEnemyManager；读取链每帧检查新层。
Ability 相关字段移动 0x8，冷却计时器现为 0x70。
保留的公共布局在 profile 的 inherited_layouts 中明确列出。

新版动作帧重新从当前资源提取。修正 Spine-Asset 1.1.1 的标量字节序适配，
独立事件样本和当前浮士德 Skill_1 均得到 OnAttack 1.3333 秒、40 帧。
格式参考：[Spine 3.8 官方实现](https://github.com/EsotericSoftware/spine-runtimes/blob/3.8/spine-csharp/src/SkeletonBinary.cs)。
