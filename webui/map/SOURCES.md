# 地图展示组件

从独立研究 demo 迁移，视觉参考 https://map.ark-nights.com/ 。
`reference.css` 为此前从官网 CSSOM 获取的样式快照，根变量改为 Shadow DOM 的 `:host`；
`definitions.mjs` 保留地块样式映射与展示定义。相关原始来源记录位于开发 demo 审计资料。
保留来源说明，不宣称取得官网资源的再发布授权。

组件只接收 WebUI 已校验和应用字段策略的地图/布局投影，不创建 WS、SSE 或内存读取链。
没有捆绑离线关卡或装置参数，不用静态配置补实时缺失数据。
`blackboard` 仅用于展示已读到的参数，不能视为完整实时地块模式。
采样失败的短暂旧值由 `stageGlobal.mjs` 管理，保留来源帧并标旧；换局、停止和策略变更清理。
地图格和实体节点按坐标/实例 ID 复用，装饰变化不销毁实体节点。

## 干员头像与配置范围

`operatorData.mjs` 保存此前研究的 463 个干员定义、73 个共享范围定义及
878 个干员头像资源索引（含变体）。该版本来自 PRTS.Map v0.49.63，不宣称覆盖当前游戏全部角色。
`operators.mjs` 使用角色 ID 或唯一名称匹配展示资料；未知 ID 不强行按名称覆盖。
普通/技能范围根据用户手动选择的阶段、技能和等级预览，不代表技能当前生效或实际攻击判定。
朝向与部署位置仍取 Timeline 布局。读取失败时随最后成功布局保留并明确标旧；
真实空名单、撤退、换局、停止或相关策略变化时清除对应的选中范围。

头像本体放在 `assets/portraits/`，使用模块相对 URL 加载，缺图时仅文字回退。
默认图标不等于当前游戏皮肤；虽然保存了索引中的变体，本轮不推测皮肤选择。
地图地块由本地 CSS 绘制，无远程字体、贴图或样式请求。
头像目录整体打包，包含 PNG 和用于维护校验的 `manifest.json`；
下载器、地图来源文档和浏览器测试不进入发布资源。

资源已经包含在 `assets/portraits/`，安装和使用均不需要下载脚本。
来源为 `https://map.ark-nights.com/assets/char_icons/`；清单记录字节数与 SHA-256，
可用于维护时核对本地资源。采集脚本仅保留在开发者本地，不是本仓库交付入口。
程序运行时不依赖此网站。
